# kb-search：经验实时检索

## 定位

预检闸门之外，开发全程在问题发生时刻打捞经验：报错/调试时、写测试前，30 秒内从 `经验/` 原子笔记定位与当前问题最相关的 ≤5 条。**检索只读**，不改动任何笔记。

## 触发时机

- **报错 / 调试失败时**：必查。检索入口 = 报错文本中的技术词
- **写测试前**：必查。检索入口 = 测试场景词（测试/夹具/mock/固定日期…）
- **重构 / 架构改动前**：随已有 ADR 流程顺带检索

## 工作流程

### 1. 解析输入

| 输入 | 必填 | 来源 |
|---|---|---|
| 报错文本 或 关键词列表 | 是 | 用户提供 / 当前错误 |
| 项目名 | 是 | 库路由查表确认注册表名 |
| 技术栈 | 否 | 当前项目（Tauri/Rust/FastAPI…） |

从报错文本抽检索词：**英文技术词 / 常量名优先**（`is_dev`、`worktree`、`ctypes`…），再补 1-2 个场景词。纯中文报错直接用原文关键词。

### 2. 库路由（定位 vault 与注册表项目名）

① 项目仓库 `KNOWLEDGE_BASE.md` 读所属 vault 与项目登记名 → ② 库级注册表（demo 为 `项目/README.md`）按项目名反查 → ③ 未登记 → 默认 demo vault、项目名原样检索，并提示补登记。经验目录为 `<vault>/经验/`。

### 3. 检索（git bash，默认 vault `D:/Desktop/knowledge base/demo`）

按序执行，结果逐步合并去重：

```bash
KB="<vault 根路径>"    # 由库路由解析，默认 D:/Desktop/knowledge base/demo
KW="<检索词>"           # 每词执行一遍，结果并集后按优先级排序

# ① 标题命中（优先）：文件名含检索词
ls "$KB/经验" | grep -i "$KW"

# ② 全文兜底：正文含检索词——纯中文标题笔记（45%）靠这步召回
grep -ril "$KW" "$KB/经验" --include="*.md"

# ③ project:通用 兜底：必合并——方法论/跨项目经验在具体项目预检里会漏读
grep -rl '^project: 通用' "$KB/经验" --include="*.md"
```

### 4. 聚合与裁剪

排序：**标题命中 > 正文命中；项目内 > 通用；多检索词命中者优先**。裁 **Top 5**。

### 5. 输出

每条一行（不打开正文），summary 必须来自 frontmatter 实际字段：

```text
[命中] <标题> | <summary> | <相对路径> | 命中词: <词1>, <词2>
```

提取 summary 用：`awk '/^summary:/{sub(/^summary: /,""); print; exit}' "<文件>"`。**不得编造或改写 summary**。

### 6. 精读（按需）

只打开与当前问题直接相关的命中正文，**精读预算 ≤1000 字**；超出只带摘要。

### 7. 留痕

命中清单记项目 `DEV_LOG.md` 一行（召回轨迹，与预检同构）：读了哪几条、跳过哪些；若本阶段踩的坑库里其实有笔记但未命中 → 记**漏招**并优先补 keywords。

## 示例

报错 `tauri build 时 is_dev 恒真`，项目「川流不息」：

1. 抽词：`is_dev`（技术词）
2. 库路由：注册表确认 vault=demo、project=川流不息
3. `ls "$KB/经验" | grep -i is_dev` → 命中 `Tauri v2 缺 custom-protocol 使 is_dev 恒真.md`（标题命中，优先）
4. 合并 `^project: 通用` 命中，按排序裁 Top 5
5. 输出每行「标题 | summary | 路径 | 命中词」；正文按需精读 ≤1000 字；清单记 DEV_LOG

## 输出协议

- 命中 ≤5 条；0 条时**如实报告「经验库无相关命中」**，不编造、不降级泛谈
- 单次注入精读 ≤1000 字（继承预检护栏）
- 结果必须可解释：每条带命中词，agent 能判断为何命中

## 边界

- **只读**：不写、不改、不移动任何笔记（蒸馏/补录走 distill-lesson 与预检守卫）
- 不做语义向量检索（二期：bge-micro-v2 已本地，待漏召审计数据支撑后接入）
- 不做自动 hook 注入（触发靠规则，不靠脚本截获报错）
- 不检索 `学习/` 目录（学习笔记非经验笔记）
- 不跨 vault 猜测：未登记项目先走库路由，未登记 → 默认 demo 并提示补登记

## 质量标准

- 结果可解释：每条带命中词与来源路径
- 纯中文标题笔记可被全文兜底召回（45% 标题无技术词是硬约束）
- 通用经验必在结果中可见（第 3 步 ③ 强制合并）
- 空结果如实报告
- 调用留痕（DEV_LOG 召回轨迹）
