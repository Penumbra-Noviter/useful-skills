# Beautiful UI — AI-Native Interface Design Language

A **component-library design language** for AI-native product surfaces (chat, agent task panels, streamed answers, human-in-the-loop approvals) — the `design-md` lock for the product register's **assistant** morphology. Unlike the other brand locks in this folder, this is **not one product's homepage** — it's a reusable token + component system for the surfaces where a user converses with an agent.

**Distilled rule layer:** `../references/ai-native-ui.md` — read it for the patterns, then this DESIGN.md for the locked tokens. When a brief is "an AI assistant / chat / agent panel" and you want this look, `match beautifului`.
