# 简单的逻辑学 — 术语词典（Bundle 参考版）

> Bundle 参考视图；完整条目含 why_it_matters 见根目录 GLOSSARY.md。

| 术语 | 作者的用法 | 与常识的差异 |
|---|---|---|
| 真相 | 本体真相（存在层）+ 逻辑真相（命题与事实符合）；本体更基础 | 常识当单一概念 |
| 命题 | 可作真假判断的语言表达；逻辑的基石 | 只说"狗"不是命题 |
| 论证 | 前提（支持）→ 结论（被证明）；目的是真相 | ≠ 争吵（求击败） |
| 真实性 vs 有效性 | 内容 vs 结构，两者缺一不可 | 常识常混为一谈 |
| 演绎 vs 归纳 | 必然 vs 可能（比"一般到个别"更准） | 归纳是演绎的基础 |
| 模糊 vs 多义 | 所指不明 vs 一词多义且上下文无法判别 | 常识混用 |
| 闪避式语言 | 掩盖真实想法的委婉；欺骗听众+扭曲使用者 | 委婉≠闪避 |
| 周延 | 项涵盖类别全部成员（全称）；中项至少周延一次 | 纯技术术语 |
| 全称/特称/单称 | 全称=全部成员；特称=部分；单称=单个个体 | 部分只能是部分 |
| 直接原因 vs 根本原因 | B vs 因果链源头 A；修 A 才治本 | 常识停在最近原因 |
| 符合论 vs 融贯说 | 命题为真=与事实相符；融贯说从属且可能荒谬 | 核查终点是事实 |
| 形式谬误 vs 非形式谬误 | 结构缺陷 vs 其余一切逻辑错误 | 谬误靠情感取胜 |
| 真诚 | 必要非充分；绝对真诚可能绝对错误 | 常识高估真诚 |
