# 决策规则速查 — 简单的逻辑学

| 能力 | 一句话规则 |
|---|---|
| 谬误识别器 | 把"哪里不对"的直觉变成谬误名称：先还原前提→结论，先查结构后查手法 |
| 论证评定器 | 四道闸：有前提？前提真？前提相关？结构有效？——任一不过即论证不成立 |
| 沟通清晰化 | 三查三改：查所指（模糊）加限定、查歧义（多义）明本意、查闪避（掩盖）翻直说 |
| 条件论证评估 | A→B 四形态：肯定前件/否定后件有效；否定前件/肯定后件无效；弱条件按联系紧密度与历史积累给"可能" |
| 事实确认 | 能亲历就亲历；不能亲历查间接证据，只有当证据链只能以"该事实为真"解释时才确认 |
| 量化审计 | 结论的量/质不能超越前提；省略量词默认按全称理解并指出 |
| 定义术语 | 先放入最相近类别，再指出区别于同类的特性；抓不住本质就用完整描述 |
| 因果链追踪 | A→B→C 追到源头 A；修 B 是治标，修 A 才是治本；先后只做嫌疑不做证明 |
| 态度根源自检 | 先问自己在求真相还是求击败；真诚是必要非充分，更要正确 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
