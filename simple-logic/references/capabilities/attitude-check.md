# 态度根源自检 (Attitude Check)

## R — 原文 (Reading)

> "论证是理性的探讨，不要将它和争吵混为一谈。论证的目的是发现真相，争吵的目的是击败你的对手。"……"真诚是正确推理的必要条件，但不是充分条件。……人要真诚，然而人更要正确。"
>
> — D.Q. 麦克伦尼，《简单的逻辑学》第4章·07 论证不是争吵、第4章·08 真诚的局限性

---

## I — 方法论骨架 (Interpretation)

很多不合逻辑的判断不是能力问题，是态度问题：在推理开始之前，门已经被关上了。本 skill 是给这道"门"做体检。

态度体检四问：

1. 我是在选择性怀疑（有疑点才质疑）还是永久化怀疑（一切皆不可知）？永久怀疑是路障，选择性怀疑才是防护网。
2. 我看到的是世界，还是我想象中的世界？玩世不恭与盲目乐观都是"预先判定"——证据不足就下结论，滤镜里的世界不是世界本身。
3. 我在求真相还是在求击败？论证的目的不是赢，是发现真相；对方只求击败时不必投入。
4. 我把真诚当正确了吗？绝对真诚可以伴随绝对错误，真诚不能把谬误变成真相。

校准工具："负面只有在正面已知时才可被确认"——能识别"不确定"，恰恰证明"确定"存在；所以先收集证据再判断，不在证据前预设立场。

一条原则：永远不要直接调动情感，努力让事实自己说话（对己对人都是）。

输出：对自身态度的诊断 + 一条可执行的校准动作。

## A1 — 书中的应用 (Past Application)

### 案例 1: 校长夫人的珍珠耳环
- **问题**: 奉命在足球场找一枚耳环，却事先决定只搜中央区域 10 米内
- **方法论的使用**: 眼界狭窄自检——问"这个搜寻范围是依据证据划定的，还是依据我的预设划定的"
- **结论**: 主观缩小范围放弃 90% 的可能区域，找到概率同比降低；眼界狭窄的拒绝缺乏理性基础
- **结果**: 预设范围与真相搜寻冲突，推理有效性被自我削弱

### 案例 2: 盲目乐观的一见钟情
- **问题**: 与初次见面的年轻女士相处一小时，即断定其有海伦的美貌、居里的智慧、戴安娜的优雅
- **方法论的使用**: 识别"预先判定"——检查判断发生在深入调查之前还是之后
- **结论**: 乐观滤镜给出扭曲的美丽现状，并预埋未来的无尽失望
- **结果**: 证据不足时的乐观与悲观同样失真；他们眼中的世界是自己想当然的世界，不是世界本身

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 讨论/评审中自己冒出"反正都一样""说不过你""别拿事实烦我"式念头
2. 多次辩论无进展，怀疑自己带着滤镜，或对方只求击败
3. 决策前情绪高涨（狂热/悲观/愤怒），担心判断失真
4. 被评价"太乐观/太悲观/太固执"，想自检是否有预先判定
5. 读到/听到煽情论证差点被带走，想先确认自己的动机

### 语言信号 (用户的话里出现这些就应激活)

- "反正都一样"
- "没有真相可言"
- "我早就知道会这样"
- "别拿事实烦我"
- "It's all the same" / "There's no truth" / "I knew this would happen" / "Don't bother me with facts"

### 与相邻 skill 的区分

- 与 `fallacy-detector` 的区别: 谬误识别器诊断推理过程中的具体谬误形态（28 种命名）；本 skill 检查推理开始前的"态度开关"——怀疑、滤镜、目标错位；态度是根源，谬误是形态
- 与 `argument-evaluator` 的区别: 论证评定评估"他人论证是否成立"；本 skill 评估"我自己是否处于求真状态"，是评定前的自我校准
- 与 `clear-communication` 的区别: 沟通清晰化治理表达；本 skill 治理接收与动机；先有求真态度，沟通才有意义

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **停下并命名当前态度模式**
   - 完成标准: 从怀疑论/不可知论/玩世不恭/盲目乐观/眼界狭窄/情感压理性/争吵模式/真诚绑架八类中识别出当前的一类或多类，写出一句话自我描述
   - 判停条件: 若识别出对方处于"只求击败"的争吵模式且无求真意愿，停止投入即可，不需要继续自检对方

2. **态度体检四问**
   - 完成标准: 对四问逐条给出"是/否 + 证据"，至少有一问的回答能指向一个具体行为（如"我刚才用'反正都一样'结束了一个本可查证的问题"）

3. **校准并执行一条动作**
   - 完成标准: 输出修正后的判断或退出决定——把判断挂起补证据、把目标重设为求真、或退出无意义争吵；校准依据能用"负面只有在正面已知时才可被确认"解释（承认不确定本身预设了确定的存在）

**输入契约**: 调用本能力需要用户当前的真实思考状态——所处讨论/决策场景、具体冒出的念头或情绪（如"反正都一样""我早就知道会这样"）、以及可锚定的言行实例；若用户只给了笼统感受而无场景与具体言行，先询问：你现在处于什么讨论或决策、冒出的是哪个具体念头/情绪、有没有一句原话可以引用。

**输出契约**: 交付当前态度模式诊断（从八类中命名一类或多类，附一句话自我描述）+ 态度体检四问逐条"是/否 + 证据"的填写结果 + 一条可执行的校准动作（挂起补证据、重设求真目标或退出无意义争吵），校准依据必须能用"负面只有在正面已知时才可被确认"解释。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用来给别人贴标签：把"你太悲观""你就是个怀疑论者"当结论输出；本 skill 是自检工具，不是评判工具
- 高压即时行动场景：先行动后自检，不在现场体检
- 需要诊断他人论证结构时：那是 fallacy-detector / argument-evaluator 的职责，本 skill 只管自己这一侧

### 作者在书中警告的失败模式

- 极端/中度怀疑论（ce29/ce30）: "没有真相"自相矛盾，"真相不可知"让逻辑整体失去意义；怀疑永久化是路障不是防护网
- 逃避性不可知论（ce31）: 把"没查清"说成"查不了"，无知从理由变成借口
- 玩世不恭/盲目乐观（ce32/ce33）: 证据不足先判死刑或先封神，预先判定且拒绝修订
- 情感压倒论证（ce35）: 情绪越紧张，清晰思维越难；"觉得美好"不是接受结论的理由
- 把论证当争吵/真诚局限/推理目的滥用（ce36/ce37/ce38）: 求击败、以真诚背书、为自我辩白而推理，都是目标错位

### 作者的盲点 / 时代局限

- 作者把逻辑缺陷归因于个人态度（懒惰、意愿），忽视结构性操纵：算法推荐、广告、宣传等系统性信息环境同样会制造怀疑/乐观/狭窄，个人自检不抵消系统诱导
- 理性人假设的残余：知道原则与践行原则之间存在巨大鸿沟，体检通过不等于行为改变；认知科学对系统性非理性（可得性偏差、确认偏误）的实证挑战未被作者处理
- 朴素符合论：作者预设"真相可认知"，但在抽象与价值领域，态度端正也可能得不到确定答案——端正态度不保证结论确定

### 容易混淆的邻近方法论

- 批判性思维态度清单：本 skill 就是它的操作化（四问 + 校准），不必外挂另一份清单
- 情商/沟通技巧：本 skill 不教如何说服或安抚人，只查推理动机
- 心理疗愈式自我关怀：自检是逻辑校准，不是情绪疏导；两者目的不同，不可混用
