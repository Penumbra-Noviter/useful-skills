# 量词审计（Quantifier Audit）

## R — 原文 (Reading)

> "整体包含部分，但是部分不能代表整体。……出现在结论中的某项的量，无论是关于主项的还是谓项的，都不能超越前提中同项的量。如果论证中的结论是否定的，那么前提中至少有一个必须是否定的。"
>
> — D.Q. 麦克伦尼，《简单的逻辑学》第3章 02-03 / 15-16

---

## I — 方法论骨架 (Interpretation)

这条方法论回答一个问题：结论说得比证据更满了吗？命题有"量"（全称"所有/每个"、特称"有些/一些"、单称单个个体）和"质"（肯定/否定）两个维度，结论必须如实反映前提。三条硬规则：全称前提可必然推出特称结论（所有的狗食肉 → 有些狗食肉）；特称前提推不出全称结论（有些女性是母亲 → 推不出所有女性都是母亲），最多只能作"可能"级别的结论；否定结论必须至少有一个否定前提（两个否定前提无法联结中项，推不出确定结论）。最常见的隐蔽故障是量词被省略："迦太基人既粗鲁又愚蠢"没有明说"所有"，却诱导听者按全称理解——被审文本省略量词时默认按全称理解并明确指出来。审计动作是：找出结论的量词与质 → 回溯前提中同项的量与质 → 逐项比对是否越界 → 越界就修正表述。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: "一些女性是母亲"推不出"所有的女性都是母亲"——特称到全称
- **问题**: "一些女性是母亲"是绝对无误的命题，但把它当成"所有的女性都是母亲"的依据就错了。
- **方法论的使用**: 检查结论的量是否被前提支撑——特称前提对全称结论不充分，"整体包含部分，但是部分不能代表整体"。
- **结论**: 有正确的前提不足以得出正确的结论，前提对结论必须充分；以偏概全是人类天性，须加倍小心。
- **结果**: 结论被降级为"可能所有女性都是母亲"或补足证据，不再宣称必然。

### 案例 2: "每个努力工作的人都是科学家"——结论的量越界
- **问题**: 前提是"每个化学家都是科学家""每个化学家都努力工作"，结论却是关于"每个努力工作的人"的全称断言。
- **方法论的使用**: 按量规则逐一比对——结论中"每个努力工作的人"是全称，而前提只覆盖"化学家"这一子集，结论项的量大过前提同项的量。
- **结论**: 前提是肯定命题时其谓项通常特称（不周延），把特称项在结论中变全称即不合逻辑，结论的必然性消失。
- **结果**: 识别出"有些"被默认为"所有"、定语被省略的量化越界机制，补上被省略的量词后论证不再成立。

### 案例 3: "没有男人是女儿；没有女侍应生是男人"——两个否定前提
- **问题**: 两个否定前提想推出"没有女侍应生是女儿"。
- **方法论的使用**: 按质规则检查——两个否定前提的影响相当于一个不周延的中项，无法联结大项与小项；女侍应生和女儿都与男人对立的事实，推不出她们两者本身对立。
- **结论**: "敌人的敌人是朋友"式直觉是错的；共享一个否定对象不等于彼此相关。
- **结果**: 论证被判定为无确定结论，最多只能说"可能"，不能断言。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户要审计一段表述或论证里的全称化断言："所有人都这么认为""他总是迟到""大家都不喜欢"——证据真的覆盖全体吗？
2. 抽样、调研报告、用户反馈里，"举几个例子"被升级为"普遍如此""大家都这样"。
3. 用户问"大部分人 = 所有人吗"，或对"省略量词的断言"（如"迦太基人既粗鲁又愚蠢"式表述）产生警觉。
4. 写总结、结论、制度条文前自查：结论的量词（所有/有些）与质（肯定/否定）有没有超出所依据的材料。
5. 反驳对方论证时，怀疑其"全称结论"来自特称或单称证据。

### 语言信号 (用户的话里出现这些就应激活)

- "所有人/大家都认为" / "everyone, everybody says / thinks"
- "总是/从不/永远" / "always, never, invariably"
- "大部分人=所有人？" / "most people = all people?"
- "举几个例子就概括" / "a few examples, then generalize"
- "他们就是这样" / "they are all like that"（省略量词的隐含全称）

### 与相邻 skill 的区分

- 与 `fallacy-detector` 的区别: 谬误识别器给错误推理命名（以偏概全、中项不周延等）；quantifier-audit 是正向审计程序——不只说出"这是以偏概全"，还逐项比对量/质并给出修正后的表述。
- 与 `argument-evaluator` 的区别: argument-evaluator 做四步整体评定（前提真实 → 相关 → 结构有效 → 量质一致），量质一致性只是其中一步；quantifier-audit 只做量/质这一维度的专项审计，可独立可组合。
- 与归纳方法论的边界: 归纳（亨利与狗实验）用样本代表整体作出概率结论是合法的科学方法——本 skill 只审计"结论量是否越出证据量"并把它降级为可能结论，不负责评估样本代表性（那是 f19 / p23 的领域）。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **标注结论的量与质**
   - 找出被审文本的结论，标注其量（全称 / 特称 / 单称）与质（肯定 / 否定）；若结论或前提省略量词，默认按全称理解，并显式写出"此处按全称理解，暗示了'所有'"。
   - 完成标准: 结论与每个关键前提的量、质都被明确标注，省略量词处已显式补注。

2. **回溯比对同项**
   - 把结论中的每个项回溯到前提，检查同项的量与质：结论中的量是否超越前提同项的量（特称→全称即越界；两个特称前提只够可能结论）；结论为否定时前提是否至少有一个否定；结论为肯定时前提是否全为肯定。
   - 完成标准: 逐项给出比对结果——全称→特称 OK / 特称→全称 越界 / 特称前提→特称结论 OK / 否定结论缺否定前提 违规 / 两否定前提 无确定结论。
   - 判停条件: 若所有比对均无越界且无省略量词，输出"量质一致"，不再继续改写。

3. **输出修正表述**
   - 对越界或违规处给出修正：把全称降为特称（"有些/部分"），把必然改成可能（"可能/很可能"），或补出缺失的否定前提；对省略量词处补写量词。
   - 完成标准: 修正后的结论其量与质均被前提完全支撑，并附一句解释指出原表述的越界机制。

**输入契约**
- 必需输入：被审计的表述或论证（含结论），且必须能回溯到其前提；若文本只有结论没有前提，应说明缺失并转交论证要素确认。
- 缺失信息：被审文本的结论与前提边界不明、或用户意图是整体论证评定（而非仅量化审计）时，应先询问目标范围再执行审计。

**输出契约**
- 交付物为审计报告：结论与各关键前提的量/质标注（含省略量词的补注）+ 逐项比对结果（OK / 越界 / 违规 / 无确定结论）+ 修正后的表述。
- 修正表述须使结论的量与质被前提完全支撑，附一句解释指出原表述的越界机制；无越界时输出"量质一致"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 归纳科学方法不适用本审计的全部规则：亨利与狗的实验在样本足够多且覆盖各类情况时，可以合法地得出关于整体的概率结论——归纳结论"只是可能"是正当的，本 skill 的职责是把结论量拉回证据范围内，而非否定归纳本身；样本代表性评估（样本够不够、覆盖全不全）请走归纳论证方法论，本 skill 不独立展开。
- 不适用于纯统计推断与概率决策场景：现实中的比例表述（"62% 用户……"）本身已标明量度，无需按全称/特称二分审计；断言"实践上可行"不等于"逻辑必然"，不要把本 skill 的必然性标准强加给概率性陈述。
- 不宜在缺乏完整论证（只有结论、没有可回溯的前提）时使用——没有前提就无从比对，此时应先用 argument-evaluator 确认论证要素是否齐备。

### 作者在书中警告的失败模式

- ce48 以偏概全（特称到全称）: 从"我遇到的几个程序员都这样"跳到"程序员都这样"；结论含"都/所有/全部"而证据是"几个/有些"，样本来源单一或对反例不感兴趣都是危险信号。
- ce50 两个特称前提: 两个"一些"前提想推出确定结论时，中项零周延、联结失效；"很可能"被升级成"必然"。
- ce52 肯定前提否定结论: 前提全为肯定句而结论为否定句（"山雀是鸟、鸟是脊椎动物，所以山雀不是脊椎动物"），结论的质与前提完全脱节——常是结论先行、倒凑前提的结果。

### 作者的盲点 / 时代局限

- 必然性理想在不确定性决策中的局限: 作者把"必然性"作为演绎结论的理想，但作者自己承认严格逻辑意义上的条件论证很少——大量现实决策没有干净的全称前提，充斥着概率与不确定性；把本 skill 的必然性标准套在真实世界决策上，与贝叶斯式概率思维相比是过时的认识论框架，审计结论应允许保留概率化表述。
- 朴素实在论残余: 量/质规则预设命题对类别的干净划分（全称/特称边界清晰），但现实中的类别常有模糊谓词（"老年人""大企业"），边界模糊时"全称 vs 特称"本身就是人为选择，审计时要先校准类别边界。

### 容易混淆的邻近方法论

- 与归纳推理: 归纳"从特称证据推出可能的一般结论"与本 skill 特称→全称的越界判定表面相似——区别在结论的定性：归纳只作"可能"，越界断言说成"必然/事实"才违规；归纳要补的是样本代表性，审计要改的是量词与必然性表述。
- 与中项规则: 两特称前提、两否定前提的失效机制与"中项至少周延一次"同构，但中项检查属于论证结构评定（argument-evaluator / fallacy-detector 的三段论分支），本 skill 只在量/质维度触碰同一病灶。
