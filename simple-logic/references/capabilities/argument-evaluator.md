# 论证评定器

## R — 原文 (Reading)

> "在评定论证正确性的过程中，第一步要确定的是，我们所要评定的论证是否是一个真正的论证。……一旦确认我们面对的是一个真正的论证后，要立刻把目光投向前提。首先，最重要的，前提是正确的吗？……在我们确定前提的正确后，下一步就要检查前提与所要得出结论的相关性，然后确认论证结构合理与否。"
>
> — D.Q. 麦克伦尼, 第3章 18 评定论证

---

## I — 方法论骨架 (Interpretation)

评定一个说法 = 按顺序过四道闸，任何一道失败即论证不成立。①真论证：前提与结论两个要素是否都在？没有支持证据的命题只是观点，可以自由接受或拒绝。②前提真实：逐条核实前提真假，尤其警惕"真假参半"——最迷惑人的论证常由部分真实、部分虚假的前提组成；对证据有一丝怀疑，使用前重新检查。③前提相关：真实但不相关的前提不能支持结论（"他很英俊"支持不了"他该当选"）。④结构有效：前提能在逻辑上搭起通向结论的桥吗？结论是必然还是仅仅可能？核心二分：真实性（内容是否反映事实）vs 有效性（结构能否推出结论），两者缺一不可——结构有效但前提错误，照样得出错误结论。反向操作即构造论证：先定结论 → 选前提 → 每个前提真实且有力 → 剔除弱前提、限制数量突出重点 → 了解听众选择表达方式。

## A1 — 书中的应用 (Past Application)

### 案例 1: 皮埃尔 vs 威尔竞选州长（前提相关性）
- **问题**: "皮埃尔是全美闻名的橄榄球运动员。皮埃尔不到 30 岁就赚到第一个 100 万美元。皮埃尔很英俊，笑容迷人。所以，皮埃尔应该被选为州长。"
- **方法论的使用**: 第三步检查相关性——名气、财富、英俊全部真实，但都不构成"州长资格"；对照威尔（维和部队 4 年、品德端正的律师、两任市长、州立法机构 12 年），公共服务履历才与结论相关。
- **结论**: 前提即使全部真实，若不与结论相关就不能有效支持结论。
- **结果**: 相关性检查成为评定程序里独立于真实性的一道闸，防"光环效应替代资格核查"。

### 案例 2: 每只狗都有三个头（前提真实性）
- **问题**: "每只狗都有三个头。牧羊犬是狗。所以，牧羊犬有三个头。"——结构完全标准的三段论，结论却荒谬。
- **方法论的使用**: 第二步检查前提真实性——大前提"每只狗都有三个头"与事实不符；结构再合理也救不了错误前提，如同做工完美的汽车油箱里灌满水。
- **结论**: 差之毫厘谬以千里；内容真实 + 结构有效缺一不可，且前提真实性要优先核查。
- **结果**: 此例确立"先验前提，再验结构"的顺序，防止被"看起来合乎逻辑"骗过。

### 案例 3: 松鼠与熊猫（结构有效性）
- **问题**: "每只松鼠都是哺乳动物。每只熊猫都是哺乳动物。所以，每只熊猫都是松鼠。"——两个前提都正确，结论显而易见错误。
- **方法论的使用**: 第四步检查结构——中项"哺乳动物"在大小前提中都是肯定命题的谓项，两次出现都不周延，无法联结大项与小项。
- **结论**: 前提真实 + 结构无效 = 论证不成立；中项必须至少周延一次才能演绎出必然结论。
- **结果**: 结构检查由此获得独立地位：前提全真也可能推不出结论，这正是"真实性 ≠ 有效性"的直观演示。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 评估商业/职场提案："我司该收购 X 公司""这个方案值得投入吗"——查前提真实、相关、结构、量质一致性。
2. 听汇报、读文章、看新闻时判断"这结论站得住吗"，把"感觉有道理"变成可执行清单。
3. 自己写提案、演讲、说服性文档之前自查：前提是否真实且有力、有没有弱前提分散注意力。
4. 招聘、评选、资格判断（皮埃尔式"他很优秀所以胜任"的拆解）。

### 语言信号 (用户的话里出现这些就应激活)

- "这说法可靠吗 / 论证成立吗 / 有道理吗 / 证据呢 / 凭什么这么下结论 / 站得住脚吗 / 前提和结论对得上吗"
- "is this argument sound / does the conclusion follow / what's the evidence / prove it / that doesn't hold up / premise"

### 与相邻 skill 的区分

- 与 `fallacy-detector` 的区别: 评定器先不问谬误名，按四步判整体成败；第 4 步结构失效时可转谬误识别器给具体形式谬误命名（中项不周延、否定前件等）。
- 与 `conditional-argument` 的区别: 条件论证是结构检查中最常见的形态之一，本 skill 在步骤 4 处理；若问题专门是"如果 A 那么 B 是否有效/有多可靠"，转条件 skill 走四形态矩阵 + 概率评估。
- 与 `fact-confirmation` 的区别: 步骤 2 的前提真实性遇到复杂核查任务（历史事件、间接证据、主观事实）时，深度核证转事实确认程序。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **确认是论证**
   - 完成标准: 能明确标出前提与结论；找不出前提 → 输出"仅为观点，无证据支撑，可自由接受或拒绝"，停止。

2. **核查前提真实性**
   - 完成标准: 每个前提逐条判定真/假/待查，标注依据；"真假参半"的命题整体不通过（单个命题中的几个主张必须全部真实）。
   - 判停条件: 任一关键前提为假 → 论证已不成立，可停止或继续诊断其余缺陷。

3. **核查前提相关性**
   - 完成标准: 每个前提回答"它支持结论吗"，不相关的前提标记并降级；结论必须是前提能"给予最大限度的直接支持"的那个。

4. **核查结构有效性（含类比论证子模块）**
   - 完成标准: 判断前提能否在逻辑上推出结论——必然（演绎）还是可能（归纳/类比）；三段论查中项周延、量/质规则；条件句查四种形态；类比论证走四查：列出共享特性 → 确认均为重要特性（数量不重要、重要性才是关键）→ 无关键遗漏（如老鼠与大象漏掉体型）→ 结论只能作"可能"而非"必然"。

5. **输出评定结论**
   - 完成标准: 给出"成立 / 不成立（卡在第几步）/ 部分成立（哪些前提待补）"，并附修改路径；对类比、归纳类结论明确标注"可能"级别而非"必然"。

**输入契约**: 待评定的论证文本，须能明确标出前提与结论（至少一个前提、一个结论）。找不出前提时输出"仅为观点"并停止；关键前提的真假涉及复杂事实核查、证据不足时，应说明待查依据，必要时转 `fact-confirmation`；原文缺失或前提/结论边界不清时，应先向用户询问补全文本。

**输出契约**: 评定结论"成立 / 不成立（卡在第几步）/ 部分成立（哪些前提待补）" + 修改路径；对类比、归纳类结论明确标注"可能"级别而非"必然"，前提逐条附真/假/待查标注与依据。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 审美与纯情感表达：没有真假判定对象的命题（"这幅画很美"）不适用真假核查，价值命题只能检查其依附的客观根基。
- 高压实时决策：火灾逃生、急救现场没有时间走四步；此时应降级为快查（只问"最关键的假设是什么"）并标注置信度，不假装完成评定。
- 对方明显在争吵而非论证：先判断模式（论证求真相 vs 争吵求击败），争吵中没有评定对象，投入是浪费。

### 作者在书中警告的失败模式

- 错误前提（ce46）：结构完美、前提为假照样得错（每只狗都有三个头）——先验前提，别被"听起来熟悉/权威"的前提默认放行。
- 前提不相关（ce47）：皮埃尔式"印象好被当资格足"，前提失效的表现之一就是不能证明结论。
- 窃取论题（ce05）：前提只是结论换说法（雪莉撒谎）——前提必须独立于结论提供支持，追问"独立证据是什么"。
- 量/质规则失败（ce50/ce51/ce52）：两特称前提、两否定前提、全肯定前提推否定结论——结构层的一致性检查不可跳过。

### 作者的盲点 / 时代局限

- 必然性理想在不确定性决策中的局限：作者把"必然结论"当论证理想，但现实中大量决策没有干净的全称前提，充斥着概率与不确定性；与贝叶斯式概率思维相比，这套框架对"该信多少"的量化能力弱——评估结论时应主动降级为概率表述。
- 事实/价值二分被当作显然：事实命题与价值命题的区分在分析哲学内部争议极大，评定时不要把"价值命题永远会被挑战"当作不需论证的公理。
- 理性人假设残余：知道评定步骤不等于会践行；真诚而错误的信念系统（如地心说）证明光有逻辑结构救不了错误世界观。

### 容易混淆的邻近方法论

- 真实性 vs 有效性：前者查内容、后者查结构，顺序不能反；"结论是假的"与"论证无效"是两个不同的失败，分开陈述。
- 评定 vs 构造：同一骨架的双向使用——评定是逐项挑错，构造是从结论倒推选前提；构造时"真实+有力"两条标准与评定四步一一对应。
- 与 `quantifier-audit` 的区别: 量/质一致性在本 skill 是步骤 4 的一项检查；专门审计"结论的量是否超越前提"时转量化审计 skill。
