# 谬误识别器

## R — 原文 (Reading)

> "错误的推理形式总称为'谬误'。最基本的谬误形式有两种，形式谬误和非形式谬误。'形式谬误'，顾名思义，问题出现在形式上，或是论证结构上。'非形式谬误'，则说的是形式谬误之外的各种逻辑错误。"
>
> — D.Q. 麦克伦尼, 第5章 引言

---

## I — 方法论骨架 (Interpretation)

谬误识别器把"哪里不对"的直觉变成可执行的诊断流程。第一步：把对方的话还原成"前提 → 结论"结构，没有前提支撑的就只是观点，谈不上谬误。第二步：检查结构——若论证是条件句或三段论，先查四种形式谬误：否定前件（A 缺席推 B 缺席）、肯定后件（B 成立推 A 成立）、中项不周延（同属一个圈子推同类）、偷换概念（一词两义使三项变四项）。第三步：结构通过后进入非形式谬误，按手法分四大类排查——转移注意力（稻草人、对人不对事、混淆视听、以笑饰非、以暴易暴）、诉诸情感（以泪掩过、情感误导、功利误导、压制理性）、错误预设（虚假假设、窃取论题、两难陷阱、以先后论因果）、错误关联（民主谬误、滥用专家意见、误用传统、以出身论英雄）。诊断原则：先结构后内容；同时命中多种谬误时，以最直接破坏论证的那个为主要谬误。输出 = 谬误名称 + 位置 + 一句"为什么它不成立"。

## A1 — 书中的应用 (Past Application)

### 案例 1: 唐璜的博爱（偷换概念）
- **问题**: 作者面对"关爱他人是利他主义的标志。唐璜是个博爱者。所以，他是个利他主义者"——听起来顺理成章，结论却荒谬。
- **方法论的使用**: 还原三项后检查中项"爱"：大前提中"爱"指利他之爱，小前提中"博爱"实指花花公子式的风流，一词两义使论证暗中变成四项。
- **结论**: 建立在不一致含义上的前提，结论必然不成立。
- **结果**: 识别出偷换概念是"比'心里有鬼'更隐蔽的多义用法"，治疗法是辩论前给关键术语定义并全程坚持（第5章 04 节）。

### 案例 2: 雪莉撒谎（窃取论题）
- **问题**: "因为雪莉在撒谎，所以，雪莉是个撒谎者"——两个命题看起来一前一后，像在推理。
- **方法论的使用**: 把前提与结论剥离对比内容，发现前提只是结论的换词重复，没有提供任何独立证据。
- **结论**: 这是把待证明的观点伪装成不证自明的前提，论证绕了一圈回到起点。
- **结果**: 确立窃取论题的识别法：追问"独立证据是什么"，答不上来就是循环（第5章 05 节，含"命运注定↔缺乏自由愿望"的循环变体）。

### 案例 3: 汉斯与恺撒俱乐部（中项不周延）
- **问题**: "几个纳粹党人是恺撒俱乐部的成员。汉斯是恺撒俱乐部的成员。所以，汉斯是纳粹党人"——同在一个俱乐部就被断定同类。
- **方法论的使用**: 检查中项"恺撒俱乐部成员"：在两个前提中都以"部分成员"面目出现，从未周延，无法联结大项与小项。
- **结论**: 汉斯只能"有嫌疑"，不能把猜测当真相宣布；嫌疑不等于定罪。
- **结果**: 此例让"中项必须至少周延一次"从小规则变成日常防牵连的武器（第5章 03 节）。

### 案例 4: 威廉博士与宇宙生命（无力反驳不算证明）
- **问题**: 威廉博士主张宇宙有其它生物，伯德博士问证据；双方都拿不出反证，威廉博士宣布"这证明我是正确的"。
- **方法论的使用**: 检查举证责任——证伪失败不等于证实成功，对方缺乏证据只是论证缺口，不是己方的正面证据。
- **结论**: 不能仅因对方不能证明你错，就宣称你对；证据缺位只支持"未知"，不支持"为真"。
- **结果**: 此例确立"谁主张谁举证"，用于拆解"你凭什么说不是"式反问（第5章 22 节）。

### 案例 5: 原始人与鸟儿歌唱（以先后论因果）
- **问题**: 原始人注意到鸟儿总在日出前歌唱，高兴地得出结论：鸟鸣导致日出。
- **方法论的使用**: 检查"先后"与"因果"的关系——原因总先于结果，但"在前"不等于"因"，两者之间有时间差且无机制解释。
- **结论**: 只有先后信息时，最多只能说"先发生的事可能是后发生事的原因"。
- **结果**: 此例成为"相关≠因果"的教科书案例，用于广告投放后销量上涨、复盘归因等场景（第5章 24 节）。

### 案例 6: 彼得出身 X 学院（以出身论英雄）
- **问题**: 人事经理仅凭彼得毕业于声誉不佳的 X 学院就拒绝他进入下一轮。
- **方法论的使用**: 拆分"来源一般坏"与"该个体必然坏"——前者是群体统计，后者是个体判定，两者之间没有必然通道。
- **结论**: 出身只能作线索，不能作判决；闪亮的新星可能出自差学校。
- **结果**: 确立两步检验：先问"他从哪里来"，更关键地问"他的品质如何"（第5章 15 节）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 辩论或讨论中直觉"这说法哪里不对劲"，需要精确命名并给出反驳理由时。
2. 阅读文章、听演讲、看广告、刷社交媒体时怀疑被操纵（情绪化标题、站队话术、权威背书）。
3. 写反驳或自查：自己的论证有没有结构洞或偷换概念。
4. 职场评审与信息审查：对一个提案、汇报、政策声明做"哪里站不住"的快速体检。

### 语言信号 (用户的话里出现这些就应激活)

- "他这话明显不对 / 偷换概念 / 避重就轻 / 人身攻击 / 大家（多数人）都这么说 / 你不信就是不懂 / 别拿事实烦我"
- "that's a fallacy / strawman / ad hominem / appeal to authority / appeal to emotion / this doesn't add up / you can't prove me wrong so I'm right"

### 与相邻 skill 的区分

- 与 `argument-evaluator` 的区别: 评定器走"有前提吗 → 前提真吗 → 前提相关吗 → 结构有效吗"四步，判整体好坏；本 skill 给已失效的论证贴具体谬误标签。发现结构无效时可转评定器走完整四步。
- 与 `conditional-argument` 的区别: 否定前件/肯定后件是本 skill 形式谬误子集，但条件 skill 正向覆盖四种形态矩阵 + 弱条件可靠性概率评估；本 skill 只做无效/有效的定性。
- 与 `quantifier-audit`、`root-cause` 的区别: 以偏概全、以先后论因果在本 skill 按手法归类定名，深度诊断（量化越界、因果链追踪）转对应专职 skill。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **提取论证结构（前提 → 结论）**
   - 完成标准: 能写出"前提1、前提2、所以结论"，或判定"这只是观点、无前提支撑"。
   - 判停条件: 无前提支撑 → 输出"非论证，仅为断言，不适用谬误诊断"，停止。

2. **形式谬误检查（结构层）**
   - 完成标准: 对条件句核对四种形态（否定前件/肯定后件/肯定前件/否定后件）；对三段论检查中项周延性、项数是否为三（偷换概念=暗中四项）、结论量与质是否被前提撑起。

3. **非形式谬误分类（手法层）**
   - 完成标准: 按四大类逐项排查（转移注意力 / 诉诸情感 / 错误预设 / 错误关联），每个命中项给出证据句；全部未命中则声明"未检出已知谬误"。

4. **输出诊断报告**
   - 完成标准: 谬误名称 + 定位（前提/结构/结论）+ 一句"为什么它不成立"+"如何修正"；同时命中多个时标注主要谬误，其余为次要。

**输入契约**: 待诊断的论证文本（口语或书面皆可），须能还原出"前提 → 结论"结构——至少一个前提和一个结论。无法提取论证结构（无前提支撑）时判定为"仅为断言"而非继续诊断；文本缺失或语境不足、还原不出完整结构时，应先向用户询问补全原文或上下文。

**输出契约**: 谬误名称 + 定位（前提/结构/结论）+ 一句"为什么它不成立"+"如何修正"。同时命中多个谬误时，以最直接破坏论证的那个为主要谬误，其余标注为次要；全部未命中时声明"未检出已知谬误"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 纯事实核查：判断"这条消息是不是真的"是 fact-confirmation 的领域，这里没有论证结构可拆。
- 日常琐碎选择或无争议陈述：没有推理冲突就没有谬误可识，强行套用等于贴标签。
- 用谬误名攻击对方：识别谬误是为了指出论证缺陷、逼近真相；把"你犯了稻草人谬误"当胜负武器，本身就是对逻辑的滥用。

### 作者在书中警告的失败模式

- 以笑饰非（ce20）：被嘲笑不等于被反驳——对方用戏谑终结话题时，论证的价值不因被嘲笑而改变。
- 真诚的局限性（ce37）：绝对真诚可能绝对错误，真诚不能把谬误变成真相；识别谬误不该被"他是真心的"软化。
- 推理目的的滥用（ce38）：结构完美可能服务于预先设定的错误结论——合乎逻辑 = 合乎真相，自洽不是免检牌。
- 极端/中度怀疑论（ce29/ce30）：识别谬误 ≠ 一切皆谬；把怀疑永久化会在推理开始前就设下路障。

### 作者的盲点 / 时代局限

- 朴素实在论 + 符合论立场：作者预设"客观真相可认知"，把逻辑缺陷主要归因于个人态度与懒惰；对"被设计来误导的系统性信息环境"（算法推荐、深度伪造、注意力经济）没有分析框架——当代谬误常是结构性的，不只在个人论证里。
- 理性人假设残余：认知科学表明知道原则与践行原则之间存在巨大鸿沟，光靠"记住 28 种谬误"防不住可得性偏差与确认偏误。
- 例证几乎全为美国语境（NFL、州长竞选），隐含"逻辑学普世客观"的假设。

### 容易混淆的邻近方法论

- 形式谬误 vs 非形式谬误：先查结构再查手法，顺序反了会漏掉结构性缺陷。
- "论证无效" vs "结论为假"：结构无效只说明结论不必然，结论本身仍可能碰巧为真；不要用"结论是假的"去反驳无效论证，也不用"结论可能是真的"替无效论证开脱。
- 与 `attitude-check`（态度根源自检）：第4章回答"为什么人不讲逻辑"（怀疑论、玩世不恭、情感压倒理性），本 skill 回答"讲了什么错"（第5章形态）；一个查病根，一个查症状。
