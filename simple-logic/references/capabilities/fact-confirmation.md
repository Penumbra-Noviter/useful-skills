# 事实确认（Fact Confirmation）

## R — 原文 (Reading)

> "如果某个事物是我们可以亲身体验的，最可靠的方法就是亲自投身其中，获得第一手资料。如果没有条件获得第一手资料，我们就必须严格考察所获间接资料的真实性及可靠性，在此基础上确认事物的真实性。"
>
> — D.Q. 麦克伦尼，《简单的逻辑学》第1章 02 确认事实

---

## I — 方法论骨架 (Interpretation)

面对"某事实是否为真"的确认任务，先按能否亲历分流。能亲身到达或体验的，直接取得第一手资料——这是最可靠路径，比如确认"狗在车库里"就到车库去看，不要在脑子里反复反思"狗"和"车库"的概念。无法亲历的（历史事件、他人的主观体验），转入间接证据审查：严格核查资料源头（官方记录、照片、证人、回忆录）的真实性与可靠性，只有所有证据只能用"该事实为真"来解释时才确认；证据不足时不强行定论，如实降级为"未证实"。判断"他人头痛"这类主观事实，完全依赖声称者的可靠性，所以先评估是否值得完全信任。配套一条观念溯源法：判断一个观念或说法对不对，不要停留在观念内部自洽，要透过观念直指其客观对象——找到对应物即确认事实，找不到（如"牛头马面"）就只是主观构造。核查的最终裁决者是客观事实，不是理论一致性，也不是多数人的看法。

## A1 — 书中的应用 (Past Application)

### 案例 1: 白宫与林肯被刺——事物与事件、直接与间接证据
- **问题**: 白宫是"事物"，林肯被刺是"事件"，两者代表事实的两种存在形式；事件无法亲历，怎么证明其真实性？
- **方法论的使用**: 确认事物可实地考察（直接观察最可靠）或可信之人证实；确认历史事件则直接证据失效，转入间接证据审查——官方记录（警局记录、死亡报告）、当时的报纸、照片、回忆录、日记、国会档案等分属不同领域。
- **结论**: 这些史料只能用"林肯被刺是事实"来解释，证据链闭合即确认。
- **结果**: 演示了"第一手资料优先、间接资料严查可靠性"的完整分流程序。

### 案例 2: 头痛——主观事实依赖声称者的可靠性
- **问题**: "头痛"是主观事实；我亲历过头痛就有第一手资料证明其真实性，但若是你头痛，我只能间接听你描述。
- **方法论的使用**: 识别这是他人声称的主观事实，确认完全依赖声称者的可靠性，必须先考虑是否值得完全信任。
- **结论**: 主观事实的确认基础是对当事人的完全信任；且人脑的自我错觉与理性化机制可能连当事人自身的事实都不可靠。
- **结果**: 确立了主观事实核查的信任评估前置步骤。

### 案例 3: 猫与牛头马面——观念必须有客观对应物
- **问题**: 我大脑中有"猫"的观念，也有"牛头马面"的观念，两者地位一样吗？
- **方法论的使用**: 透过观念直指对象——"猫"能在现实世界中找到对应物；"牛头马面"找不到任何对应物，只是大脑中的主观事实。
- **结论**: 观念能感知的来源是独立于意识的客观事物；脱离客观根源的观念不可靠。
- **结果**: 演示了"为观念找到对应物即确认事实"的溯源验证法，是后续一切事实核查的观念学基础。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 查证新闻、传言、转发消息："网上说……可信吗""这是真的吗"。
2. 判断历史事件或自己无法亲历的客观事实（他人经历、远地事件、已发生事故）。
3. 采信他人转述或声称（"某人说某人怎样""他说他做了 X"），需要评估该不该信。
4. 检验自己或他人的一个"想法/信念"是否确有现实对应（"我的这个判断有事实依据吗"）。
5. 信息审查时识别"多数人这么说""专家这么说"是否足以作为结论的依据。

### 语言信号 (用户的话里出现这些就应激活)

- "这是真的吗" / "is this true, really?"
- "网上说……可信吗" / "I saw online that…, can I trust it?"
- "你怎么知道" / "how do you know?"
- "谁说的" / "who said it? who told you?"
- "大家都这么说" / "everyone says so"（触发证据来源审查，而非采信众数）

### 与相邻 skill 的区分

- 与 `argument-evaluator` 的区别: argument-evaluator 评估"论证结构是否有效、前提是否相关"，结构审查发生在前提被假定之后；fact-confirmation 核查"前提事实本身是否为真"，是评定程序的第一步且可独立使用。
- 与 `fallacy-detector` 的区别: 谬误识别器给错误的推理形式命名（无力反驳不算证明、滥用专家意见、民主谬误等）；fact-confirmation 是这些谬误的正面替代程序——不满足于识破错误，而是给出正确的核查路径。
- 与 `clear-communication` 的区别: clear-communication 治理表达是否含混；fact-confirmation 核查所指对象是否真实。一句话可以很清楚但完全是假的，先分清任务再选 skill。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **分流定性**
   - 把待核查对象分清楚：是"事物"还是"事件"？是客观事实还是他人声称的主观事实？能否亲身到达或体验？
   - 完成标准: 明确对象类型与亲历可行性，据此选定路径（直接观察 / 间接证据审查 / 声称者评估）。

2. **按路径核查**
   - 能亲历 → 直接观察取第一手资料，记录观察结果；不能亲历 → 收集间接证据（多个独立来源：记录、照片、证人、档案），逐一评估各来源的真实性与可靠性，检查证据链是否只能用"该事实为真"来解释。
   - 完成标准: 给出证据链评估结论——证据充分一致 / 证据冲突 / 证据不足。
   - 判停条件: 若证据不足且无法补证，停在此步，结论明确降级为"未证实（缺乏充分证据）"，不强行判定真假。

3. **主观事实与观念溯源**
   - 对象是他人声称时，评估声称者可靠性（是否有理由歪曲、是否有能力知情）；对象是观念或断定时，为其在外部世界找对应物，找不到即标注为主观构造。
   - 完成标准: 输出核查结论及置信级别（已证实 / 大概率但非必然 / 未证实 / 无法核查），并说明依据。

**输入契约**
- 必需输入：待核查的说法或命题（"这是不是真的"的对象），以及该说法的来源或出处（谁说的、从哪里看到）。
- 缺失信息：说法来源不明、或目标对象可能出自虚构/不可核查语境时，应先询问来源与核查目的，再判定走哪条路径。

**输出契约**
- 交付物为核查报告：对象分流结论（事物/事件、客观/主观声称、能否亲历）+ 证据链评估（充分一致/冲突/不足）+ 最终结论与置信级别。
- 最终结论只能落在"已证实 / 大概率但非必然 / 未证实 / 无法核查"四档内，并附一句依据说明；证据不足必须明示降级，不强行定真假。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 不要用此 skill 去"证明"不可验证的价值判断：审美、道德、偏好类命题（"泰山是秀美的""这是不公平的"）没有可直接核查的客观对应物，本 skill 的核查程序无法为它们定罪或洗白——价值命题需要的是论证而非事实确认。
- 不宜用于论证结构评估：前提"是否真实"确认后，论证"是否有效"交给 argument-evaluator，本 skill 不评判推理链。
- 面对"被设计来误导"的系统性信息环境（深度伪造、算法推荐），单点证据审查有效但有限——来源造假可以成体系，核查需扩展为跨源交叉验证，超出单次事实确认的常态假设。

### 作者在书中警告的失败模式

- ce22 无力反驳不算证明: 对方拿不出反证 ≠ 己方主张成立；证据缺口只支持"未知"，不支持"为真"，举证责任在主张者一方。
- ce10 民主谬误: 多数人赞同 / 点赞多 / 销量高都不能替代事实判断——"大家同意"是心理学现象，不是真理论据。
- ce13 滥用专家意见: "专家说"不能成为论证终点——专家意见必须附带理由、限于其已建立威信的领域，检验标准是"如何通过论证得到它"而非身份。

### 作者的盲点 / 时代局限

- 朴素符合论: 作者把"命题与客观事实相符"视为可核查的自明前提——在"狗在车库里"这类具体领域成立，但在社会科学与抽象领域（法律、金融、美学），命题与事实的对应关系并不像日常物证那样可直接核查，核查标准本身需要更多约定。
- 事实/价值二分争议: 作者把事实命题与价值命题的二分当作显然（"价值命题永远会被挑战"），但这一二分在分析哲学内部争议极大；用本 skill 时不要默认"凡价值判断都不可核查"。
- 认识论乐观主义: "只要方法对就能确认事实"低估了观察渗透理论（同一证据在不同范式下解读不同）与现代认知科学揭示的系统性非理性；本 skill 的"证据链闭合即确认"应理解为高置信而非绝对。

### 容易混淆的邻近方法论

- 与 general skepticism: 选择性怀疑（有疑点才质疑、拿到有效证据即接受）不同于把怀疑永久化；本 skill 是核查程序，不是"一切皆不可知"的态度。
- 与 Bayesian 式溯源: fact-confirmation 以"证据链只能用该事实为真来解释"为判定标准，接近高置信推理而非严格概率更新；在证据相互依赖（同源转述）时，仍需手动检查证据独立性，不要把 N 条互相抄的转发当成 N 个独立来源。
