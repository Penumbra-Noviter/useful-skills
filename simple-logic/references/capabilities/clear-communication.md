# 清晰沟通（Clear Communication）

## R — 原文 (Reading)

> "避免产生歧义的方法是，让你所运用的词语尽可能有针对性地反映出你的本意，以便读者或者听众不用费心去猜测你所说的到底是什么。……闪避式语言不能直接地表达出演讲者或是作者脑中的真实想法……使用者塑造语言，同时语言也塑造使用者。"
>
> — D.Q. 麦克伦尼，《简单的逻辑学》第1章 07-09

---

## I — 方法论骨架 (Interpretation)

沟通失败多半不是词汇量问题，而是表达没对准本意。这条方法论先把语言失效分成三种可诊断的病灶：模糊（听者不知道你指什么，如"人们不喜欢那样的音乐"）、多义（一个词有多种含义且上下文无法判别，如路牌"熊向右"）、闪避（用委婉语掩盖真实想法，如"终极方案"）。治疗分两步：先定位病灶类型，再按改写程序处理——补全被省略的主语与量化词，给模糊词加限定定语，把双重否定和委婉语翻回直接表达。要点是"尽可能有针对性地反映出本意"，让听者不用费心猜测。闪避式语言有双重危害：欺骗听众，同时反过来扭曲使用者对现实的感受——所以治理它不只是礼貌问题，是认知卫生问题。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 林间路牌"熊向右"——多义导致灾难性歧义
- **问题**: 一条林间小径路口竖着路牌"熊向右"，护林人本意与旅行者理解可能完全相反——可能是"请向右走"，也可能是"右边有熊出没"。
- **方法论的使用**: 识别这是多义（双关语）失效：同一句话有两种含义，上下文无法判别所指，必须明确本意。
- **结论**: 避免歧义的唯一方法是清楚表明本意；护林人语言一时的不谨慎可能带来灾难性后果。
- **结果**: 作者给出改写示范——"向左走，不要向右走，那里有熊出没"，歧义随所指明确而消失。

### 案例 2: "人们不喜欢那样的音乐"——模糊使真假无从判定
- **问题**: 这句话里"人们"指谁？"那样的音乐"是哪样的音乐？命题因指代不明而失去真假判定的基础。
- **方法论的使用**: 识别这是模糊（所指不明）而非多义：关键名词缺少限定定语，听者只能凭默认理解脑补。
- **结论**: 模糊与多义"游走于不同观念之间"，没有固定无可争议的内涵，必须先找出命题含义才能谈真假。
- **结果**: 治疗方式是给模糊词加特定定语、补全量化词，把"人们/那样的"替换为明确的主语与限定。

### 案例 3: "终极方案"——闪避式语言的双重危害
- **问题**: 一个委婉语被用来掩盖罪恶的灭绝人类的计划，听者无法从字面得知真实所指。
- **方法论的使用**: 识别闪避式语言的双重机制：欺骗听众只是第一层，第二层是扭曲使用者自身对现实的感受。
- **结论**: 使用者塑造语言，语言也塑造使用者；持续使用扭曲现实的语言，人会逐渐相信自己编造的虚假世界。
- **结果**: 沟通治理要求尽量直抒胸臆，识别并拒绝让委婉语成为信息缺漏的根源。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户对一段话（自己的或别人的）感到含混，要求"说清楚/改清楚/别绕弯子"。
2. 写作、汇报、需求沟通、合同或制度表述前，需要自查有没有模糊词、省略的主语或暗示性的量化词。
3. 对话中反复出现"我说的不是这个意思"——事后补救说明表达本身留了歧义空间。
4. 面对组织沟通、广告宣传或对外声明，需要识别委婉语是否在掩盖关键事实。
5. 翻译或转述一段话时，发现原文有不止一种合理解读，需要先消歧再传达。

### 语言信号 (用户的话里出现这些就应激活)

- "这话有歧义" / "他到底什么意思" / "ambiguous, unclear, what do you mean"
- "他们说要调整" / "他们说会处理"（主语缺失 + 闪避式动词）
- "帮我改得清楚点" / "把这段话说明白" / "make it clearer, rephrase this"
- "这段话没说明白" / "没说清楚" / "this doesn't make sense to me"
- "委婉点说" / "别说得太直接"（需要判断是否滑向闪避式语言）

### 与相邻 skill 的区分

- 与 `define-terms` 的区别: define-terms 聚焦"单个术语"的精确界定（最相近类别 + 特殊不同点），是单点定义；clear-communication 聚焦"整段表达"的模糊/多义/闪避清理，是全局改写。
- 与 `fallacy-detector` 的区别: 谬误识别器诊断"论证结构或内容"的错误（含偷换概念等利用多义词的谬误）；clear-communication 在语言层治理歧义本身，防止歧义演变成谬误，不评判论证对错。
- 与 `fact-confirmation` 的区别: fact-confirmation 回答"这个说法是否为真"，clear-communication 回答"这个说法是否清楚"；前者核查所指对象的真假，后者只保证表达不含糊。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **三查定位病灶**
   - 通读被审文本，逐句执行三查：查所指（能否确定指什么？模糊？）、查歧义（是否一词多义且上下文无法判别？）、查闪避（委婉语是否掩盖了真相？）。
   - 完成标准: 列出每处可疑句及其病灶类型（模糊 / 多义 / 闪避），无可疑句则列表为空。

2. **按病灶改写**
   - 补全主语与量化词（谁？哪些？）→ 替模糊词加限定定语（"那样的"→具体属性）→ 负负得正、委婉翻直白（双重否定改成直接肯定；"终极方案"类措辞换成直陈）。
   - 完成标准: 每个可疑点都有对应改写，改写后本意明确、无需听者脑补。
   - 判停条件: 若步骤 1 列表为空（无模糊、无多义、无闪避），直接跳到步骤 3 的复核或结束，不强行改写。

3. **复核唯一解读**
   - 重读改写结果：是否存在第二种合理解读？是否掩盖或扭曲了事实？对闪避类改写，额外确认改写后没有丢失信息。
   - 完成标准: 改写后的句子只有一种合理解读，且忠实表达原意（对闪避句则是忠实表达被掩盖的真实所指）。

**输入契约**
- 必需输入：被审文本（一段话或整篇表达）、改写诉求或"说清楚"的意图；若对象是他人言论，需一并说明上下文。
- 缺失信息：改写目的（面向读者/听众、正式度）、原话的真实本意不明时，应先询问本意再改写，不替作者脑补。

**输出契约**
- 交付物为"病灶清单 + 改写对照"：先列出各可疑句的病灶类型（模糊/多义/闪避），再给出逐句改写，最后附复核结论。
- 复核结论须声明"仅剩一种合理解读"或指出残留歧义；无病灶时输出空清单并明确"无需改写"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户要核实"这话是不是真的"而非"这话清不清楚"——那是 fact-confirmation 的职责，本 skill 只保证表达不含糊，不负责判定真假。
- 用户要做的是论证对错评定（前提真实、结构有效）——本 skill 不评判论证，交给 argument-evaluator / fallacy-detector。
- 不要把本 skill 用作给所有委婉语定罪：作者明确"委婉语可以很重要"，只有成为信息缺漏根源的闪避式语言才需要治理；日常礼貌性委婉不在打击范围。
- 面对被设计来系统性误导的宣传文本，光靠逐句改写治标不治本——那是结构性操纵问题，本 skill 只能做到让单句不失真。

### 作者在书中警告的失败模式

- ce40 模糊与多义语言: 模糊（所指不明）与多义（一词多义无法消歧）让命题失去真假判定的基础；关键名词缺少限定定语、一句话可有多种合理解读，都是危险信号。
- ce41 闪避式语言: 双重危害——欺骗听众 + 反向扭曲使用者；"使用者塑造语言，语言也塑造使用者"的反馈环会让使用者逐渐相信自己编造的虚假世界。
- ce04 偷换概念: 多义词是偷换概念的温床——同一词在论证中换义，论证实际变成四项而失效；本 skill 在语言层的消歧正是这道防线的源头。

### 作者的盲点 / 时代局限

- 个人归因忽略结构性操纵: 作者把语言失效主要归因于个人（懒惰、有意留退路、态度），很少讨论结构性因素——利益驱动的系统性语言污染（广告、宣传、舆论操纵）在书中只有零散提及，未形成分析框架；治理个人表达不等于抵御体系化操纵。
- 朴素符合论局限: "语言必须忠实表达客观事物"在具体可核查对象（狗在车库里）上成立，但在抽象领域（法律、金融、美学）词语与事实的对应关系并不那么直接可核查，"忠实表达"标准需要更多限定。

### 容易混淆的邻近方法论

- 与 define-terms: 有人会把"给模糊词下定义"当成沟通清晰化的全部——其实定义只解决单个术语，整段表达的歧义（省略主语、量化词缺失、委婉掩盖）仍需三查程序。
- 与 argument-evaluator: "表达清楚"不等于"论证正确"——清晰地把错误论点说清楚仍是错误论证；先治表达，再评论证，两步不能合并。
