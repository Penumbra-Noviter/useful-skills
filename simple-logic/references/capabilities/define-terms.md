# 定义术语 (Define Terms)

## R — 原文 (Reading)

> "逻辑上定义术语的过程分为两步：第一步，将要定义的术语放入最相近的类别当中；第二步，确定其与同类中其他事物的不同特性。"……"如果你要公正地就某一点进行辩论，首先请给你所要辩论的观点一个明确的定义，并且在整个辩论中始终如一地坚持它。"
>
> — D.Q. 麦克伦尼，《简单的逻辑学》第2章·06 定义术语、第5章·04 偷换概念

---

## I — 方法论骨架 (Interpretation)

模糊词（公平、正义、合理、好的开发体验）之所以吵不清，是因为同一个词被不同的对话者装进了不同的内容。此刻要做的不是继续争，而是先把词钉住。

定义分两步：

1. 把被定义项放进"最相近的类别"——够用就好，别贪宽（"人"归"动物"，不归"有机物"），也别太窄。
2. 指出它在同类里独一无二的"特殊不同点"，把它与同类的其他成员分开。

实战用两问："它最像的'类'是什么？""在这个类里，它凭什么跟别人不一样？"

两步齐备，就得到一个精确鉴别（如：正义 = 社会美德 + 使每个成员得到其所应得）。

若暂时抓不住本质、定义不出来，不要硬编——改用"完整描述"：把可观察到的现象尽可能说全，描述可能揭示本质线索。

辩论场景追加一条纪律：开始前先定义关键术语，全程坚持同一含义；对方用到一半换义，就是偷换概念，当场指出。

## A1 — 书中的应用 (Past Application)

### 案例 1: 亚里士多德定义"人"
- **问题**: 怎么定义"人"，使其与其他事物清楚区分
- **方法论的使用**: 第一步放入最相近类别"动物"（而非过宽的"有机物""自然物"）；第二步指出特殊不同点"理性"
- **结论**: 人 = 理性的动物；"动物"给出类，"理性"给出差异性
- **结果**: 成为经典定义；过宽类别会把人与性质不同之物混为一谈

### 案例 2: 定义"正义"与"害怕"
- **问题**: 两个相当困难的模糊术语，词典式同义替换治不了
- **方法论的使用**: 正义 = 社会美德（类）+ 使每个社会成员得到其所应得（不同点）；害怕 = 情绪（类）+ 促使我们逃避所感知的危险（不同点）
- **结论**: 两个术语都因"类 + 独特差异"而精确，且能与礼貌、慷慨、宽容等相邻词区分
- **结果**: 模糊词获得可检验的边界；即使"类"不够唯一，第二步的不同点仍能完成鉴别

### 案例 3: 定义"移动电话"
- **问题**: 需要把移动电话与世界上其他通信器材区分开
- **方法论的使用**: 第一步类别取"通信器材"；第二步列举若干特殊不同点把它与座机、对讲机等区分
- **结论**: 逻辑定义的独特价值在于揭示所定义事物的本质
- **结果**: 抓不住本质时退而用完整描述，描述可能揭示本质线索

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 需求评审/产品讨论中"公平""好的开发体验""合理"被反复使用，但各方理解不一致
2. 争论陷入"各说各话"、越辩越远，尚无一方给核心词下过定义
3. 写作、制度、规范或接口命名遇到含义过宽的词，需要钉死边界
4. 对方论证中某个大词中途变义（怀疑偷换概念），需要指认
5. 双方看似在争事实，实际是词义约定不同

### 语言信号 (用户的话里出现这些就应激活)

- "什么叫公平/正义/好的开发体验"
- "先定义一下 X"
- "这个词没说明白"
- "每个人的'合理'不一样"
- "Define X first" / "What do you mean by fairness?" / "Clarify the term" / "That's not what I meant by X"

### 与相邻 skill 的区分

- 与 `clear-communication` 的区别: 沟通清晰化治理模糊/多义/闪避语言的"表达"问题；本 skill 提供构造词义的"定义"程序，是沟通清晰化的前置工具
- 与 `fallacy-detector` 的区别: 偷换概念只是该 skill 诊断的 28 种谬误之一；本 skill 是预防它的正向方法（先定义并坚持）
- 与 `fact-confirmation` 的区别: 事实确认核查"命题与客观事实是否相符"；本 skill 协商"词指什么"，先立约定再谈真伪

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **定位并确认为词义分歧**
   - 完成标准: 摘出 1-3 个反复出现且无定义的关键术语，并确认各方对它的理解确实不同（让各方各用一句话说明"我理解的 X 是什么"，内容不一致即成立）
   - 判停条件: 若分歧本质是事实差异或价值冲突、不是词义差异，则不用本流程，转入事实核查或论证评定

2. **两问构造定义**
   - 完成标准: 输出"X 属于 Y（最相近类），特殊不同点是 Z"，且 Y 不过宽（不混入性质不同之物）、不过窄，Z 能把 X 与 Y 中其他成员区分开
   - 判停条件: 若连续尝试仍找不出合适类别或不同点，走步骤 3 的"完整描述"替代路线，不硬编定义

3. **描述兜底与回代检验**
   - 完成标准: 对无法定义的概念给出尽可能完整的可观察描述；把定义/描述回代到原对话，双方对核心词含义达成一致；辩论场景声明"全程按此定义使用"，并能指出对方换义的具体位置

**输入契约**: 调用本能力需要有反复出现且无统一定义的关键术语，以及各方对它的理解陈述（各用一句话说明"我理解的 X 是什么"）；缺少这些时，先向用户询问：核心术语是哪几个、各方各自如何理解、分歧发生在哪段对话或哪份文本。

**输出契约**: 交付"X 属于 Y（最相近类），特殊不同点是 Z"的精确定义，定义不成立时退为完整描述；附回代验证结论——双方对核心词含义达成的约定，辩论场景下附"全程按此定义使用"的声明及换义指认。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 分歧不在词义而在事实或价值观本身（如"该不该拨这笔预算"），定义解决不了，需要事实确认或价值论证
- 术语已有权威定义（法律条文、技术规范、行业标准），此时引用权威定义而非重新发明
- 诗歌、玩笑、品牌文案等故意留白的语言，较真定义反而破坏表达

### 作者在书中警告的失败模式

- 偷换概念（ce04）: "爱"在大前提指利他、在小前提指风流，一个词两种含义让论证从三项变四项，结论必然落空
- 模糊与多义（ce40）: "熊向右"式表述，指代不明或无法消歧，真假判定失去基础
- 分类错误（ce18）: 最相近类别选错（苹果当橙子），后续一切检索、推理、应对都建在错误地基上

### 作者的盲点 / 时代局限

- 作者假定词义可稳定锚定在客观事物上（朴素符合论），但法律、金融、美学等抽象领域的语词意义是社会建构的，共识要靠协商而非"发现"
- 事实/价值二分被当作显然，而"公平""正义"这类价值词定义时无法绕开价值立场，作者未加论证

### 容易混淆的邻近方法论

- 查词典/找同义词: 定义是"类 + 差异"的鉴别，不是同义替换
- 操作化定义（实证研究）: 把概念转成可测量指标是定义的特殊窄化形态，覆盖不了"价值词"这类难以量化者
- 分类学: 类别的选择直接决定定义成败；分类错误会传导到定义（见 ce18）
