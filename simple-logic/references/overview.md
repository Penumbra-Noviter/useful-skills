# 简单的逻辑学 — 整书概览（Bundle 参考版）

> 本文是 Capability Bundle 的 `book/overview.md` 参考视图，来源于阶段 0 的 BOOK_OVERVIEW.md（更完整版见根目录同名文件）。供编译入口与能力卡引用。

## 一句话主旨

把逻辑学从一门学科压成可执行的思维习惯：先搭注意力与事实观的地基，再立四大基本原理，用"论证"正向构造推理，靠识别 28 种谬误完成防御——目标是让合乎逻辑成为"第二本能"。

## 骨架（5 个一级论点，层层递进 + 正反对照）

1. 思想准备（第1章）：全神贯注、确认事实、观念—语言—事实三者的正确关系
2. 基本原理（第2章）：同一律/排中律/充足理由律/矛盾律 + 定义、直言命题、因果分析工具
3. 论证构造（第3章）：前提→结论、演绎（三段论与量质规则）、归纳、评定与构造
4. 非逻辑思维的根源（第4章）：怀疑论、玩世不恭、眼界狭窄、情感压理性、论证非争吵、真诚局限
5. 非逻辑思维的主要形式（第5章）：28 种谬误，先结构后手法分类诊断

第 1→2→3 章自下而上建造正确推理，第 4→5 章从上到下建立防御；后记明言"避免陷阱固然重要，但更应花精力领会正确原则"。

## 核心方法（9 能力一览）

| 能力 | 一句话 | 出处 |
|---|---|---|
| fallacy-detector | 谬误识别：先还原前提→结论，先结构后手法 | 第5章 |
| argument-evaluator | 四步评定：有前提？前提真？相关？结构有效？ | 第3章 |
| clear-communication | 模糊/多义/闪避三查三改 | 第1章 |
| conditional-argument | A→B 四形态 + 弱条件可靠性评估 | 第3/5章 |
| fact-confirmation | 第一手优先，间接证据严查来源 | 第1章 |
| quantifier-audit | 结论量/质不超前提，省略量词按全称理解 | 第3章 |
| define-terms | 最相近类别 + 特殊不同点 | 第2章 |
| root-cause | A→B→C 追到根本原因，先后≠因果 | 第2/5章 |
| attitude-check | 求真相还是求击败；真诚≠正确 | 第4章 |

## 作者盲点（进入各能力 Boundary 的批判来源）

- 朴素符合论认识论，未回应后现代/观察渗透理论挑战
- 事实/价值二分未论证
- 把逻辑缺陷归于个人态度，忽略结构性操纵
- "必然性"理想在现代不确定性决策中可操作性有限——最大实战价值在防御侧
