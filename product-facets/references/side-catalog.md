# 面目录

候选面的全集。基础面恒在；条件面由 f 按基调拉入。每面给定义 + 风险 FLAG（f 用它做「提示器」）。

## 基础面（恒在）

| 面 | 定义 | 风险 FLAG |
|---|---|---|
| 功能面 | 产品做什么 | 功能能跑、其他面裸奔（本 skill 反的就是这个） |
| 责任面 | 法律/合规/免责 | 逆向→实质相似审查；平台对抗→ToS 灰区；数据→个保法；第三方 IP→版权；商用→EULA/授权 |
| 安全面 | 攻击面/威胁模型 | 本地 REST/远程窗/WS token；供应链；多租户 |
| 发布面 | 打包/分发/交付门 | 商店审核；包管理发布；版本策略；交付门断言 |

## 条件面（由 f 拉入）

激活条件引用轴 A/轴 B 时，即指该值成立（如「轴 B『数据类型』」= 采集个人数据），不另设判断。

| 面 | 激活条件 | 风险 FLAG |
|---|---|---|
| UI/交互面 | 有人机界面（GUI/CLI/API 各为不同交互形态） | 无障碍；可用性 |
| 运维/可观测面 | 有服务端 | 监控/告警/事故响应 |
| 文档面 | 库/SDK/开源 | API 文档缺失 |
| 兼容/维护面 | 库/API 对外 | semver/破坏性变更 |
| 隐私/数据面 | 轴 B「数据类型」成立 | 权限/隐私政策/数据治理 |
| 成本/计费面 | SaaS/订阅 | 定价/计量/订阅 |
| 商店审核面 | 移动 App | 平台政策拒审 |
