# 每面协议

每面的设计 / 落地 / 校验协议。责任 / 安全 / 发布三面有本项目真实样本支撑（已验证）；功能 / UI 与条件面为首版草图（未验证）。协议是「可独立设计/落地/校验」的最小单元，执行时路由给对应 skill。

## 责任面

- **设计**：风险分级（按轴 B 的关系类型列出每条风险 + 强度）→ 免责声明 + 商用时的 EULA/授权条款。
- **落地**（真实样本）：免责声明单一源 + 首启同意 gate；授权系统（激活码 + 设备绑定）；法律文本与免责声明无漂移。
- **校验**：交付门机械断言（样本清除 / 构建隔离 / 法律文本非空 / 免责声明整句锚定 / 商用元数据齐全），任一 FAIL 阻断打包。
- 参考资产：`check-delivery-gate.js`（D-001~005 断言）、`docs/authorization-design.md`。

## 安全面

- **设计**：威胁模型，列最高级差距（真实样本 G-1 本地 REST 无鉴权 / G-2 远程内容窗零拦截 / G-3 WS token 泄面）。
- **落地**（真实样本）：REST 一次性 token 鉴权（fail-closed 中间件）；远程内容窗导航/新窗/权限三拦截；WS token 移出 query。
- **校验**：鉴权中间件动态遍历测试（真实样本 255 用例）；导航守卫白名单测试。
- 参考资产：`SECURITY_HARDENING.md`、导航守卫（`src/electron/` navigation-guard）。

## 发布面

- **设计**：打包形态 + 交付门开关清单。
- **落地**：electron-builder 产出；`delivery:check` + `prepack` 钩子。
- **校验**：`check-delivery-gate.js` 断言，任一 FAIL 退出码 1 阻断打包。
- 参考资产：`scripts/check-delivery-gate.js`。

## 功能面

- **设计**：行为规格（本项目 `BEHAVIOR_SPEC.md`——做什么、数据怎么流）。
- **落地**：垂直切片，先 MVP 再稳定性/体验/性能。
- **校验**：域补验清单（本项目六域：登录/采集/AI/直播/授权/附加），真实环境逐域验收。
- 参考资产：`BEHAVIOR_SPEC.md`、`docs/real-verification-checklist.md`。

## UI/交互面

- **设计**：界面形态（GUI/CLI/API）。
- **落地**：本项目 renderer（Vue3）。
- **校验**：组件测试（vitest）+ 真机走查。
- 首版草图，未验证。

## 隐私/数据面

- **设计**：数据清单（采集什么 / 为什么 / 存多久 / 给谁）→ 采集最小化 → 去标识化 → 用户知情/同意。
- **落地**：权限申请最小化；隐私政策（告知采集范围 / 用途 / 保留期）；只采必要字段；去标识化（移除或哈希可直接识别信息）；数据保留与删除策略。
- **校验**：数据清单完整（每类数据都有「用途 + 保留期 + 删除路径」）；同意 gate 生效（未同意不采集）；保留期满自动删除跑通过一次。
- 法律侧（个保法等）：只标「需核验法条原文」，不在本 skill 断言具体法条；引用 D-003 的「采集最小化 + 去标识化 + 评估个保法边界」清单，法条由交付前人工核验。
- 参考资产：本项目 D-003（`TO-TICKETS.md`）「线索采集最小化 / 去标识化」。

## 运维/可观测面

- **设计**：出故障怎么被发现 → 监控 / 告警 / 事故响应。
- **落地**：日志 + 指标 + 告警；事故响应预案（谁响应 / 怎么止损 / 怎么复盘）。
- **校验**：有监控告警且事故响应跑通过一次（真实触发或演练）。
- 通用运维实践，非本项目真实样本。

## 成本/计费面

- **设计**：定价 → 计量 → 订阅 / 一次性。
- **落地**：计费/订阅系统；用量计量；发票/对账。
- **校验**：一次真实交易全链路跑通（下单 → 扣费 → 交付 → 对账）。
- 通用 SaaS 计费实践，非本项目真实样本。
