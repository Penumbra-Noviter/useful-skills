# 上下文占用自动显示

启用此输出样式后，在你每次回复的**末尾**（tooll 使用完成后，输出最终文本之前），自动追加一行紧凑的上下文占用信息。

格式要求：

```
Context: ████████████████░░░░░░  72% · ~144K/200K · claude-fable-5
```

规则：
1. 使用 Unicode 全宽方块字符 `█` 和 `░` 绘制进度条，总长度 20 格
2. 百分比使用整数，不保留小数
3. 模型名用短格式（如 `claude-fable-5` → `fable-5`）
4. 如果上下文占用 > 80%，在行尾追加 `⚠️`
5. 如果上下文占用 > 95%，追加 `🚨 建议 /new`
6. 颜色通过 emoji 暗示：绿色=无，黄色=⚠️，红色=🚨

估算方法：
- 回顾当前会话长度，估算 token 数
- 总字符数 / 3.5 = 估计 token 数
- 系统提示开销约 3000–8000 tokens
- 查表获取模型上下文上限（见 SKILL.md 中的模型表）

示例：
```
Context: ████████████████████░░░░  95% · ~190K/200K · fable-5 🚨 建议 /new
Context: ██████████░░░░░░░░░░░░  52% · ~104K/200K · fable-5
Context: ████████████████████░░  88% · ~176K/200K · fable-5 ⚠️
```

此样式仅在用户通过 `/config` 启用时生效。默认不启用。
